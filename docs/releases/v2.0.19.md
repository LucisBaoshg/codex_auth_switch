# Codex 助手 v2.0.19

- 下载和更新共享配置时校验授权文件、配置文件和版本。文件缺失或请求失败会停止应用。
- 后台同步将云端版本写入本地同步记录。命令行（CLI）拉取先保存档案，通过切换命令应用。
- 应用前备份运行配置。未通过 OAuth 刷新或文件在应用期间发生变化时，保留原运行凭据。应用故障会尝试恢复已修改的文件。
- 官方 OAuth 和共生共享档案使用各设备本机的 Codex 登录。现有共享档案可继续下载配置。发布新的 OAuth 档案时，仅共享需要本机登录的说明。
- 共享服务提供一致版本的配置包，并统一校验旧接口的写入基线。共享服务与桌面和命令行需要分别部署或升级。

如果设备上的旧授权已经失效，先在 Codex 正常登录一次，再使用新版助手应用共享配置。使用系统钥匙串（Keyring）的配置需要确认运行时从文件读取凭据，才适用助手的文件切换。
