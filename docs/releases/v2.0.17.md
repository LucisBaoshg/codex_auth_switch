# v2.0.17 正式版

第三方模型配置现在可以分别设置可选推理强度和默认推理强度。保存后，Codex 的模型菜单会展示配置中选定的档位；移除默认档位时，助手会自动选取剩余档位作为默认值，并防止移除最后一个档位。

- 每个模型可单独设置推理档位，实际支持范围以第三方接口为准。
- 模型列表、显示名称、上下文预算、默认档位和可选档位随配置保存，导入另一台机器时自动生成其本地模型目录。
- 兼容未包含可选档位字段的旧配置，继续保留其原有推理设置；普通单模型配置和官方登录的处理方式保持兼容。
- 共享网站支持保留全部推理档位，并过滤本机模型目录路径。网站配套代码需要单独部署，应用发布流程不会自动部署网站。
- 修复测试中后台定时器未清理导致的 Windows 发布失败，以及模拟接口读取不完整请求造成的偶发测试失败。

安装包覆盖 Windows、macOS Apple Silicon、macOS Intel，以及 Linux x64 命令行版（CLI）。

发布前已验证双模型的真实工具调用、模型目录读取、配置重新打开，以及移除原机器目录后的跨目录迁移。只保存本机绝对目录路径且未包含模型定义的旧配置，需要在新版助手中补全模型列表后重新共享。

本地发布检查通过：前端 241 项、桌面端 Rust 155 项、命令行版 35 项、共享网站 44 项测试，以及前端构建、Rust 格式和静态检查（Clippy）。使用真实网关密钥的自动化测试默认跳过；双模型工具调用已通过独立的隔离配置验收。
