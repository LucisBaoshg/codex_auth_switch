# Codex 助手 v2.0.21

- 恢复官方授权（OAuth）共享。发布者可把本机授权发布到原共享档案，获得访问权限的成员可下载并应用同一个账号的授权。
- 应用共享档案时直接使用档案的有效凭据。同一个账号已有更晚刷新过的本机凭据时，优先使用本机的那份。
- 共享中心继续校验修订和访问权限。旧版助手发布仅含登录方式的文件时，服务保留已共享的授权。
- 查看远端档案详情时，助手隐藏令牌的值。包含共享授权的档案会显示授权可用于应用。

此前云端仅保存登录方式的档案需要发布者更新一次。发布者在自己设备上启用对应档案并完成 Codex 登录，然后点「发布本机配置」。成员升级后可下载并应用这份档案。
