# v2.0.18 正式版

第三方模型目录现在会声明文本和图像输入，Codex Desktop / CLI 才能贴图或使用 `--image`。这只解开 Codex 这一侧的能力门禁；网关和模型是否接受图像仍以实际接口为准。

- 生成的第三方模型目录将 `input_modalities` 设为 `["text", "image"]`，不再默认写成只支持文本。
- 不自动宣称原生联网搜索能力。
- 2.0.17 及更早版本在切换配置时仍会重新生成 text-only 目录。要稳定支持贴图，需要安装本版本后再切换一次当前配置。
- 服务器 20 的 `grok-4.6` 与 `gemini-3.8-flash-high` 已用真实网关做过图像探测；其他网关不可直接套用。

安装包覆盖 Windows、macOS Apple Silicon、macOS Intel，以及 Linux x64 命令行版（CLI）。

发布前已完成本机安装与当前第三方配置切换：生效目录为文本加图像。本地发布检查通过：前端 241 项、桌面端 Rust 155 项、命令行版 35 项、共享网站 44 项测试，以及前端构建、Rust 格式和静态检查（Clippy）。使用真实网关密钥的自动化测试默认跳过。网站无需随本版本单独部署。
