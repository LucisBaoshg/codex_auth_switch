# v2.0.16 正式版

独立第三方接口（API）配置现在支持获取模型列表、筛选与多选模型，也可手动添加完整模型名称。保存后可再次打开配置，修改默认模型、显示名称、推理设置和上下文预算。

- 模型设置随配置保存，跨机器导入时重新生成本机模型目录；保留旧目录供配置备份恢复。
- 编辑和切换新第三方配置时保留本机工具、项目、审批与沙箱设置；切回官方账号时恢复其模型目录。
- 默认上下文预算为 32,768，额外推理默认关闭；这些是本地默认值，实际能力需要向接口服务商确认。
- 模型列表请求不会跟随重定向，错误提示不会回显接口密钥。
- 共享网站增加模型元数据兼容处理，过滤本机绝对路径；使用模型配置的在线共享能力需要共享网站也部署相应代码。应用正式版发布流程不部署网站。

安装包覆盖 Windows、macOS Apple Silicon、macOS Intel，以及 Linux x64 命令行版（CLI）。

发布前已通过前端 240 项、桌面端 Rust 153 项、命令行版 35 项和共享网站 43 项测试，以及前端构建、Rust 格式与静态检查（Clippy）。需要真实网关密钥的可选测试未执行。
